# Reference

Lookup tables, not explanations.

- [Command line](cli.md) — every command and flag.
- [Terminal UI](tui.md) — slash commands, keys, and rebinding them.
- [Built-in tools](tools.md) — every tool the agent can be given, and what
  each one does.

The `sennitrc` command reference lives with the rest of configuration:
[sennitrc reference](../configuration/sennitrc.md). The JSON
schema for the legacy format is
[`schema.json`](https://github.com/rave-soft/sennit/blob/main/schema.json), and
`sennit schema` regenerates it.
