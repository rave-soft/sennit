Launch a new agent that has access to the following tools: fetch, web_fetch, web_search, glob, grep or ripgrep (whichever this system provides), ls, view. When you are searching for a keyword or file and are not confident that you will find the right match on the first try, use the agent tool to perform the search for you.

Set background: true to hand the prompt off as a background task instead of waiting for it: the call returns right away with the task's id, session id, and status, not its answer — the result follows later, separately. Use background for read-only or research work you don't need the outcome of immediately, such as investigating a question or gathering context while you keep working. Leave background unset for anything that edits files, or whose result you need before continuing: a background task runs concurrently with you, and asking it to edit files at the same time you might be editing them is not yet supported.
