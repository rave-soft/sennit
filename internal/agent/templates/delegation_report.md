The delegated agent reports back on its own. A default `agent` call returns its terminal result inline. A `background: true` delegation delivers its final message as a completion: into the next step of this turn if you are still working, and if you have already ended the turn, it wakes the session and you continue from there.

The default delegation call waits for the terminal event and makes its report available to your next provider step. Set `background: true` only when useful work can continue independently; its report starts or folds into a later turn. Use `agent_wait` when the next action depends on selected background delegations. A person's message interrupts either wait; respond to it while the delegation continues. The durable inbox can also deliver the same terminal outcome returned inline: correlate by delegation and child-session id and do not repeat work already done from that outcome. Do not call `agent_result` or `agent_output` round after round to pass the time. Correlate reports by task and child-session id, and since several may arrive in any order, never infer which request finished from arrival order.
